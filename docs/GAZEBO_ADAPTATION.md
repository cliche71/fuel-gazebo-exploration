# Gazebo 移植说明

本项目基于官方 FUEL 提交 [`662dd23`](https://github.com/HKUST-Aerial-Robotics/FUEL/tree/662dd23c7b52b258d3c4a0155ff6632118e8984f)，保留前沿搜索、探索目标选择、访问顺序、连续重规划和原探索结束流程，并适配 Gazebo Classic 与 RotorS。

## 仿真、传感器与控制接口

- 将办公室点云转换为 Gazebo 物理场景，使用147个碰撞盒表达主要场景几何。
- 使用 RotorS Hummingbird 及其机体、旋翼碰撞体和 Lee 控制链。
- 配对深度图、`CameraInfo` 和实测里程计，保持相机光学位姿、时间和单位一致。
- 将米制 `32FC1` 轴向深度转换为规划器使用的毫米制 `16UC1` 图像。
- 将机体系测得的速度转换到世界坐标，将 FUEL `PositionCommand` 转换为 RotorS 的 `MultiDOFJointTrajectory` 命令。
- 保留命令起始时间、未来命令缓冲、过期命令及非有限值检查，并检查命令的速度、加速度和 yaw rate。
- 将起飞悬停、初始化准备和开始探索分为独立阶段。

Gazebo 保存完整世界几何，用于生成模拟观测；FUEL 的占据、膨胀和距离地图通过相机观测逐步建立。完整办公室几何没有直接作为已经探索的地图交给规划器。

主要接口位于 `src/fuel_gazebo_official_baseline/`，场景资源位于 `src/fuel_gazebo_official_world/`。

## 相机投影与校准

`fuel_camera_adapter` 提供实际深度投影插件，配合机体生成脚本同步设置渲染光心和光学坐标系。

| 项目 | 当前设置 |
| --- | --- |
| 图像尺寸 | 640×480 |
| 水平 / 竖直视场 | 80° / 60° |
| 渲染 near / far | 0.1 / 5 m |
| 实际 `CameraInfo` 的 fx / fy | 约381.3611603 / 415.6921864 |
| cx / cy | 320 / 240 |

这些设置作用于实际投影，不只是修改 `CameraInfo` 的数字。规划器在传感器配对及相机标定就绪后启动。

渲染裁面、深度过滤、地图射线和视点范围是不同环节。当前深度过滤为0.2–5米，最短射线0.5米，最大射线和视点距离4.5米；详细参数见 [参数说明](PARAMETERS.md)。

## 构建与数值处理

为适配当前环境及运行中出现的边界输入，包含以下修正：

- 通过 CMake 查找 NLopt C++ 头文件和库。
- 处理短路径、重复点、退化路径和样条边界输入，检查输入与输出的有限性。
- 改善轨迹构造和优化失败时的返回与状态处理。
- 修正深度遍历中当前像素的读取顺序。
- 初始化地图局部索引边界，避免首次深度更新前访问未初始化范围。

这些修改涉及错误处理和部分计算结果，并非只有 ROS 话题重映射。

## 转向、候选恢复与时间优化

当前实现还包含：

- **连续转向修正**：检查连续 yaw 曲线的速度和加速度，处理边界和失败返回。
- **候选完整恢复**：构造候选轨迹前保存位置、转向及元信息，失败时恢复，成功后提交，避免留下部分更新的状态。
- **周期角差处理**：使用圆周角差计算转向时间下界，避免跨越 ±π 时选取长角差。
- **时间梯度修正**：修正边界加速度误差对样条时间间隔求导时的系数。

转向修正不代表所有终点朝向均被精确满足，相关约束与目标仍需结合实际输出理解。

## 运动与地图参数适配

当前默认速度、加速度配置分别为 1.0 m/s、1.0 m/s²，原 0.6 m/s、0.6 m/s² 配置作为可选项保留。两份配置仅五项速度和五项加速度不同；障碍膨胀仍为0.35米，轨迹优化距离参数为0.7米。观点连接搜索预算为0.05秒，实际飞行路径 A* 预算为1.0秒。

这些取值针对当前 Gazebo / RotorS 条件，不代表论文所有参数的严格复现。优化中的运动和距离约束并不保证实际运动始终满足相同数值。

## 执行余量与限期截停

在轨迹生成后和发布前，检查即将执行的约2.1秒轨迹：

- 地图膨胀和0.1米距离余量。
- 曲线内部速度及加速度。
- 不满足条件时拒绝候选并恢复完整状态。

规划器可以按轨迹编号与绝对期限发送截停请求，执行端接收后缩短有效执行期，提前量为0.05秒。到达截停时刻后进入固定目标保持。

固定目标保持不等于飞机同一时刻已经停住，也不构成连续物理制动或整机连续无碰撞保证。当前仍有状态判断、贴墙和停滞方面的 [已知问题](KNOWN_LIMITATIONS.md)。
