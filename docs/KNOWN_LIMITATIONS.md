# 已知问题与适用范围

## 接触与停滞

当前1.0 m/s、1.0 m/s²配置的五轮测试中，4次自然 FINISH，1次旋翼与墙面接触。保留的0.6配置测试中也出现过接触，以及截停后保持位置、仍有活动前沿但持续找不到路径的情况。两套配置均有完成办公室探索的记录，不能保证每次完成。逐轮数据见 [测试结果](VALIDATION.md)。

## 未知地图状态判断

执行前缀检查中仍存在状态码判断缺陷：实现以 `occupancy == -1` 判断 unknown，而地图中 `UNKNOWN = 0`，`-1` 表示越界。该检查不能视为对真实未知区域的完整处理。

现有记录没有证明这一缺陷是历史碰撞的唯一原因。地图更新、参考轨迹、跟踪误差和截停时序也会影响实际结果。

## 软约束与停止距离

规划中的速度、加速度和避障距离包含软约束。当前速度配置为1.0 m/s，五轮最高实测速度约1.52～1.63 m/s；原0.6配置也有超过其配置值的记录。0.1米距离余量不是实际跟踪误差的上界。

限期截停最终进入固定目标保持，不是连续物理制动。目标速度归零时，机体仍可能继续移动；前缀中心检查也不是整机连续无碰撞证明。

1.0配置的接触轮中，截停请求已收到并切换为保持目标，机体随后约0.14秒内仍移动约0.149米后接触墙面。该记录说明保持指令不等于机体立即停住；不能把接触前位移当成完整停车距离，或单凭这一轮确定唯一原因。

## 探索结束与观测

FINISH 沿用原无可覆盖活动前沿条件，允许少量残余未知、小前沿及休眠前沿，不代表所有可达体素都已被观测。路线图和占据点数量也不能直接作为覆盖率。

相机的渲染裁面、深度过滤、射线和视点距离作用不同。`CameraInfo` 消息数量不等于独立深度图帧率。

## 使用范围

当前结果集中在办公室场景、Hummingbird、前向深度相机和 Lee 控制器。其他场景、传感器、机体或控制器需要另行测试。本项目的配置与仿真条件不同于论文全部实验设置，不能直接用于同条件性能比较，也不是实机部署验证。
