# 测试结果

测试环境为 Ubuntu 20.04、ROS Noetic、Gazebo Classic 11.15.1、RotorS Hummingbird 与办公室场景。以下均为 Gazebo 仿真结果，不是实体无人机试飞。

## 结果含义

- FINISH 来自原规划器“没有可覆盖活动前沿”的条件，不使用倒计时判定完成，不要求100%覆盖或未知区域全部清零；少量小前沿、休眠前沿及残余未知可能仍然存在。
- 结果支持当前配置能够在办公室场景完成探索，同时仍存在偶发停滞和碰撞风险。
- 实测路程由探索期间的里程计逐段累计；速度、加速度配置包含软约束，不能作为实际运动的硬上限。
- 相同 Gazebo seed 不能锁定 ROS 调度、在线地图更新或限时优化的停止时序。
- 样本量和场景范围有限，不据此估计长期成功率或与论文原仿真作同条件性能比较。

完整运行数据包括里程计、原始规划命令、实际发送命令、状态、接触记录和规划日志。仓库保留结果摘要与必要小型记录，完整大数据不随源码分发。相关问题见 [已知限制](KNOWN_LIMITATIONS.md)。
