# Gazebo 适配改动

## 0.6.0

默认采用已进行五轮办公室测试的 1.0 m/s、1.0 m/s² 配置，保留原 0.6 配置。启动脚本支持 `--profile` 选择，两种入口使用一致的默认配置。五轮结果为四次自然完成、一次旋翼碰墙，详见 [测试结果](../../docs/VALIDATION.md)。

## 接口与规划适配

当前接口提供传感器与坐标转换、相机校准、轨迹命令转换、独立初始化，以及执行前轨迹检查和限期截停。

相对官方 FUEL 的构建兼容、数值处理、转向和状态恢复修正详见 [Gazebo 适配说明](../../docs/GAZEBO_ADAPTATION.md)。当前配置见 [参数说明](../../docs/PARAMETERS.md)，已知问题见 [已知限制](../../docs/KNOWN_LIMITATIONS.md)。
